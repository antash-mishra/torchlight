Torchlight · project overview

Find your files. Fast.

A Linux launcher that finds files and folders by their names and paths. The resident background service keeps search ready and follows file changes. The popup searches applications, settings, files and folders.

What is built

  • Terminal commands to index folders and search.
  • A saved file list, folder settings and skip rules.
  • Search by exact name, beginning of a name, short forms, small typos and parent folders.
  • Support for names in other languages and unusual file names.
  • Safe refreshes: unavailable folders keep saved entries; write failures undo the whole refresh.
  • Resident search, automatic file watching, restart recovery and status.
  • Optional search/open history with clear and retention controls.
  • Automated checks and speed tests at 50,000 and 500,000 paths.

M2 review: both findings fixed

Reviewed commits 0c97097 and dc5fd51. The sanitizer suite and lint pass with new regression coverage; both original reproductions now pass.

  • Replacement files retire stale IDs. Scans compare filesystem identity, so delete/recreate gives the replacement a fresh ID and makes old selections stale. Directory replacement also retires descendant IDs; failed updates restore the old IDs and history.
  • Inotify exhaustion keeps rescans working. When no new instance is available, scanning continues with degraded watch status. Later scans retry setup, and an existing watch set stays live until a replacement is ready.

Schema v2 preserves legacy IDs/history and adopts identity on the first successful scan. Without filesystem birth time, metadata changes may also retire IDs conservatively. See the fixes, regression coverage and reproduction details.
