Tekst: Nordic calm with a teletext memory

The Nordic broadcasters kept teletext running long after everyone else: NRK Tekst-TV, SVT Text and Yle Teksti-TV still publish pages today. Tekst takes that page's information design (page numbers, colour-coded sections, inverse-video highlights and the four coloured links) and sets it on quiet Scandinavian surfaces with generous space.

1. Design language

The theme

Calm, light-filled surfaces in two schemes, Snø (snow) and Mørketid (the polar night). Colour is rare and always means something: each kind of result keeps one teletext colour, shown as a small square block, never as a wash. The selected row is drawn in inverse video, the way a teletext page highlights a line.

Linux-native

From Libadwaita it takes the 14px window radius, flat layered shadows and a hairline border, and it follows the system's light or dark preference. From Kirigami it takes list sections with quiet headers and an inline detail pane. From current launchers it takes the two-pane palette with a preview and motion that explains what changed.

The retro half

Bedstead, a free recreation of the teletext character set, sets everything the system says: the page header, counts, folders, metadata and keys. A clock ticks in the header with teletext's slash seconds. Closing switches the page off like a CRT.

Visual hierarchy

The query is the largest thing on screen. Below it, results are grouped into teletext-style sections, each with its colour block and count. The preview panel on the right is quieter, set on a slightly darker surface. The header and Fastext lines are smallest: they frame the page without asking for attention.

Search bar states

  • Empty: compact, with only the header, the query line and an idle strip of index status. The placeholder rotates through tips, such as “Try raedme: typos are fine”.
  • Active: the caret blinks in lingonberry red; the dotted rule waits.
  • Typing: the rule draws from left to right in ink, the icon darkens, the count in the header ticks.
  • No matches / offline: said inline at the end of the line in teletext type, with Retry.

Results as pages, not a pile

Results are grouped by kind: Apps, Settings, Folders, Files. Groups are ordered by their best match, so the strongest result is always on top; inside a group the daemon's ranking stands. Running apps keep their windows beneath them. Arrow keys move through every row in display order.

Preview panel

Files show their type, size, modified time and folder; folders show how many items they hold; apps show their description, open windows and actions; settings show what they manage. Every action is listed with its key. With an empty query the panel is hidden and the idle strip shows the index status instead.

Building it in GTK

  • Every effect is opacity, transforms, colour and stepped keyframes, which GTK CSS animates. The CRT switch-off is a transform plus a brightness filter on the surface.
  • Light and dark: GTK 4.14 has no colour-scheme media query, so the view adds a dark class from the desktop's preference and the stylesheet carries both palettes, split into two resources to stay within the embedding limit.
  • Grouping is a reordering in the popup model; the daemon and its ranking do not change.
  • The preview reads file size and dates with asynchronous GIO calls, and app descriptions from their desktop entries off the main thread, so typing never waits.
  • The chosen fonts (Bedstead is CC0; Doto, Familjen Grotesk and Schibsted Grotesk are OFL) would be vendored and registered at startup, which adds fontconfig as a direct dependency; or installed once to ~/.local/share/fonts. Double height needs only Bedstead's Ultra Condensed cut and font-stretch, which GTK CSS supports.
  • Suggested order: the look and motion first, then grouping, then the preview panel.
