M7 baseline profiles (2026-10-10). Companion to 2026-10-10-m7-baseline.jsonl.
Sampler: LD_PRELOAD shim, per-thread CLOCK_THREAD_CPUTIME_ID timers at 500 Hz (2 ms of thread CPU per
sample), frame-pointer stacks, symbolized with nm (libc via /usr/lib/debug). Time inside a system call is
charged to the libc wrapper (fstatat64, statx, pread64, ...). Thread names are thread start routines:
worker = writer indexing thread, persistence_worker = SQLite owner, search_worker = search thread,
worker_loop = search pool, main = IPC loop. "incl" = share of samples with the function anywhere on the stack.
