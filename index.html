Torchlight

A Spotlight-style launcher for Linux: press a shortcut, type a few letters, and open an application, a settings panel, a file or a folder. For Linux Mint 22 and Ubuntu 24.04 or newer, on 64-bit PCs.

Install

Download the .deb from the latest release and open it, or install it from a terminal:

sudo apt install ./torchlight_*_amd64.deb

The package adds this site's signed APT repository, so your update manager installs new versions like any other update.

Or add the repository yourself

sudo curl -fsSLo /usr/share/keyrings/torchlight-archive-keyring.gpg \
  https://antash-mishra.github.io/torchlight/apt/torchlight-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/torchlight.sources \
  https://antash-mishra.github.io/torchlight/apt/torchlight.sources
sudo apt update && sudo apt install torchlight

Then

Bind torchlight-gtk --toggle to a keyboard shortcut in your desktop's settings (Cinnamon: Keyboard, Shortcuts, Custom Shortcuts). The search daemon starts with your session.
